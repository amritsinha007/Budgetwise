Jaleba BudgetWise - Flask + SQLite

PowerShell:
  cd "Jaleba-BudgetWise-Flask-SQLite"
  python -m pip install -r requirements.txt
  python app.py
Then open http://127.0.0.1:5000

The database is budgetwise.db. Frontend files are templates/index.html, static/css/style.css, static/js/script.js.
SQLite tables: users, profiles, transactions, budgets, categories, bills, subscriptions, emis, app_state.
